Admin login

Connect this dashboard to your GitHub repository once. It publishes by saving files to your repo, so no server is needed.

How do I get a token? (one-time, 2 minutes)
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Give it any name, set an expiry (e.g. 1 year).
  3. Repository access → Only select repositories → choose vedikawellness.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate, copy the token and paste it above.

The token stays only in this browser. Use Log out on shared computers. Anyone who opens this page without the token can do nothing.
